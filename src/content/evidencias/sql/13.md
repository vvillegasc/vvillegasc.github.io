---
nivel: "Nivel 4 · Avanzado"
title: "Los 3 salarios más altos de cada departamento."
---

```sql
WITH ranking AS (
  SELECT department_id, first_name, last_name, salary,
         DENSE_RANK() OVER (PARTITION BY department_id
                            ORDER BY salary DESC) AS puesto
  FROM   employees
  WHERE  department_id IS NOT NULL
)
SELECT department_id, puesto, first_name, last_name, salary
FROM   ranking
WHERE  puesto <= 3
ORDER BY department_id, puesto;
```
